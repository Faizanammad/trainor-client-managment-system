# Trainer-Client Management System 🏋️‍♂️

A C++ console-based application to manage trainer and client data, built using object-oriented programming concepts. This project demonstrates usage of classes, vectors, input/output handling, and basic security features like password verification.

---

## Features

- Trainer login system with password verification
- View trainer profile and expenses
- Add, view, search, and delete clients
- Maintain client progress reports
- Gym package details and workout plans
- Track total number of clients

---

## Technologies Used

- **C++**: Core programming language
- **Object-Oriented Programming**: Classes, inheritance
- **Vectors**: For dynamic client storage
- **Standard Libraries**: `<iostream>`, `<string>`, `<cstdlib>`, `<vector>`
